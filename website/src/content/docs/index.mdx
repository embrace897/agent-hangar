People create agents where they already work: Claude, ChatGPT, Cursor, VS Code, Codex, OpenCode. Agent Hangar
brings them all to one place, runs each one in its own container, and makes them usable from **any** platform:
OpenAI-compatible, MCP, A2A and ACP, and inside your own app over AG-UI. Everyone can find them, talk to them, and
combine them into new agents.

## Why Agent Hangar

<CardGrid>
  <Card title="Built where you already work" icon="laptop">
    Ask Claude, ChatGPT, Codex or Cursor for an agent. It is built, tested and shipped through the Hangar MCP, with no
    new tool to learn.
  </Card>
  <Card title="Usable from anywhere" icon="random">
    Every agent speaks OpenAI-compatible, MCP, A2A and ACP, and runs inside your own app over AG-UI.
  </Card>

  </Card>
  <Card title="Cost under control" icon="information">

    for simple requests.
  </Card>
</CardGrid>

## Quick start

<Tabs>
  <TabItem label="Linux, macOS, WSL">
    ```bash
    git clone https://github.com/valteresj2/agent-hangar && cd agent-hangar
    ./scripts/install.sh
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    git clone https://github.com/valteresj2/agent-hangar; cd agent-hangar
    powershell -ExecutionPolicy Bypass -File scripts\install.ps1
    ```
  </TabItem>
</Tabs>

The guided installer writes `.env`, starts the stack, registers and tests your LLM, creates the admin and generates
the configuration of your AI tools. `hangar doctor` checks the result. See [Installing Agent Hangar](/agent-hangar/install/)
for the requirements, a cloud VM or Kubernetes.
